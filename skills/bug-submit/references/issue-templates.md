# Issue 描述模板

## 单个 bug

```
## 复现步骤
1. 进入 [具体页面]
2. [点击/输入/操作]
3. [下一步操作]

## 预期结果
[正常情况下应该发生什么]

## 实际结果
[实际出现了什么，比如报错、无响应、显示异常]

-----------

## 代码分析

**涉及文件：**
- `path/to/file.ts`（L行号）：[这段代码的问题是什么]
- `path/to/file2.ts`（L行号）：[这段代码的问题是什么]

**根因链：**
1. [触发点]
2. [中间传导]
3. [最终表现]

**代码证据：**
（贴出有问题的关键代码片段，用注释标出问题所在）

## 最优解决方案

**修改 `path/to/file.ts`：**
（贴出具体修改方案，越具体越好）
```

## 合并多个相似 bug

用于「Step 2：读代码验证 + 排查相似 Bug」发现同页面/同类功能中存在相同根因的多个 bug 时，合并为一个 issue：

```
## Bug 1：[功能A] 具体现象

### 复现步骤
1.
2.

### 预期结果 / 实际结果

---

## Bug 2：[功能B] 具体现象

### 复现步骤
1.
2.

### 预期结果 / 实际结果

-----------

## 代码分析

**共同根因：**
[说明为什么这些 bug 同根同源]

**涉及文件：**
- `path/to/file.ts`（L行号）：[问题]

**根因链：**
1.
2.

**代码证据：**

## 最优解决方案

（统一修复方案）
```

标题反映共同问题，不要只用其中一个子 bug 的现象当标题。
